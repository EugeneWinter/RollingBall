# Лабораторная работа №1: Катящийся шар

Учебный проект по Unity. Игрок управляет сферой, собирает объекты на трёх уровнях с нарастающей сложностью.

## Стек

- **Unity** 2022.3.62f3 LTS (Built-In Render Pipeline)
- **C#**

## Геймплей

- Управление сферой через `WASD` / стрелки (движение относительно камеры)
- Сбор вращающихся объектов-триггеров
- Физика через `Rigidbody.AddForce`
- Ветер, зоны ускорения и замедления
- Таймер прохождения уровня
- 5-секундный обратный отсчёт при победе → загрузка следующего уровня
- Автоматический перезапуск при падении за край

## Уровни

| # | Описание | Сложность |
|---|----------|-----------|
| 1 | Плоское поле, слабый боковой ветер | Лёгкий |
| 2 | Две платформы + мост, удалённый остров с рампой и ускорителем | Средний |
| 3 | Узкий мостик с ускорителем и ветром, замедлитель, скат к третьему острову | Сложный |

## Структура проекта

```
Assets/
├── Scripts/
│   ├── PlayerController.cs   # Управление, сбор, ветер, победа/поражение
│   ├── CameraController.cs   # Плавная следящая камера
│   └── Rotator.cs            # Вращение подбираемых объектов
├── Materials/
├── Prefabs/
├── Scenes/
│   ├── Level1.unity
│   ├── Level2.unity
│   └── Level3.unity
```

## Как открыть

1. Установите [Unity 2022.3 LTS](https://unity.com/releases/editor/qa/lts-releases)
2. Откройте Unity Hub → **Add** → укажите папку проекта
3. Откройте сцену `Scenes/Level1`
4. Нажмите **Play**
