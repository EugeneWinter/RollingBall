# Лабораторные работы по Unity (C#)

Учебный репозиторий, содержащий комплекс лабораторных работ по разработке 3D/2D приложений в среде Unity.

---

## 🚀 Лабораторная работа №1: Катящийся шар

Разработка базовой механики катящегося шара с физикой, сбором предметов и усложнённым рельефом.

### Особенности:
- **Управление сферой:** на основе физических сил (`Rigidbody.AddForce`) относительно направления камеры.
- **3 составных уровня:** 
  - *Уровень 1:* плоское поле со слабым ветром.
  - *Уровень 2:* платформы на разной высоте, мостики, рампа и ускорить для перелёта на остров.
  - *Уровень 3:* Г-образная трасса, узкий мостик, диагональный ветер, зона ускорения и зона замедления.
- **Интерактивные элементы:** собираемые объекты-триггеры, зоны ускорения (`BoostZone`) и замедления (`SlowZone`).
- **Следящая камера:** плавное перемещение через `Vector3.Lerp` с фокусировкой на игроке (`LookAt`).

---

## 🎨 Лабораторная работа №2: Пользовательский интерфейс

Полноценная система UI, связывающая уровни в единый игровой цикл с сохранением прогресса.

### Особенности:
- **Стартовое меню (`MainMenu`):**
  - Кнопки навигации («Старт», «Помощь», «Выход»).
  - Всплывающая панель помощи с инструкцией по управлению.
- **Экран загрузки (`LoadingScreen`):**
  - Вынесен в отдельную сцену для оптимизации памяти.
  - Фоновая асинхронная загрузка через `SceneManager.LoadSceneAsync()`.
  - Визуализация прогресса через компонент `Slider`.
  - Ожидание ввода игрока перед активацией сцены.
- **Выбор уровней (`LevelSelect`):**
  - Горизонтальная прокрутка через `ScrollRect` и `RectMask2D`.
  - Заглушки «Скоро...» для демонстрации работы скролла.
  - Динамическая система разблокировки уровней на основе пройденного материала.
- **Внутриигровое меню паузы (`PauseMenu`):**
  - Вызов по кнопке или клавише `Escape` с остановкой времени (`Time.timeScale = 0`).
  - Функции возобновления, перезапуска уровня и выхода в главное меню.
- **Система прогресса и звёзд:**
  - Оценка прохождения уровней (1–3 звезды) в зависимости от времени.
  - Передача данных между сценами через класс-синглтон (`GlobalData`).
  - Автоматическое сохранение лучших результатов.

## 📂 Структура проекта

```
Assets/
├── Scripts/
│   ├── PlayerController.cs        # Физика игрока, ветер, зоны, обработка победы/поражения
│   ├── CameraController.cs        # Плавная следящая камера
│   ├── Rotator.cs                 # Вращение подбираемых предметов
│   ├── GlobalData.cs              # Паттерн Singleton для передачи данных между сценами
│   ├── MainMenuController.cs      # Логика главного меню и панели помощи
│   ├── LoadingScreenController.cs # Асинхронная загрузка с прогресс-баром
│   ├── LevelSelectController.cs   # Меню выбора уровней, замки и звёзды
│   └── PauseMenuController.cs     # Внутриигровое меню паузы
├── Materials/                     # Материалы пола, стен, зон и игрока
├── Prefabs/                       # Префабы подбираемых предметов
└── Scenes/
    ├── MainMenu.unity             # Индекс 0: Главное меню
    ├── LoadingScreen.unity        # Индекс 1: Экран загрузки
    ├── LevelSelect.unity          # Индекс 2: Выбор уровня
    ├── Level1.unity               # Индекс 3: Уровень 1
    ├── Level2.unity               # Индекс 4: Уровень 2
    └── Level3.unity               # Индекс 5: Уровень 3
```

---

## 🛠 Технологии и стек

- **Engine:** Unity 2022.3.62f3 LTS (Built-In Render Pipeline)
- **Language:** C#
- **UI System:** Unity UI (Canvas, ScrollRect, RectMask2D, CanvasScaler)
- **Architecture:** Singleton, Async Operations, Coroutines

---

## 🎮 Инструкция по запуску

1. Откройте проект в **Unity 2022.3 LTS**.
2. Откройте сцену `Assets/Scenes/MainMenu.unity`.
3. Нажмите кнопку **Play**.
